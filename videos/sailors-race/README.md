# سباق البحّارة — أوائل الحلقات

فيديو احتفالي (1920×1080، ٣٠ إطارًا، نحو ٦٢ ثانية) مبنيّ بـ HyperFrames.

## تعديل الأسماء
1. عدّل `data.json` (الأول والثاني لكل حلقة، ورقم الحلقة المتميزة).
2. `node build.mjs` يولّد `index.html`.
3. `npx hyperframes snapshot --at 9.8,13.1,38.4,48.6` للفحص.
4. `npx hyperframes render -o out/video.mp4 --quality delivery`.

لا تظهر النقاط في الفيديو. لا تعدّل `index.html` يدويًّا؛ فهو يُولَّد من `build.mjs`.

## المشاهد
| الزمن | المشهد |
|---|---|
| ٠–٦٫٤ | الافتتاحية |
| ٦٫٤–٤٠ | الحلقات الأربع، ٨٫٤ ث لكل حلقة: اسم الحلقة ثانيتين، ثم الأول، وبعد ٣ ث الثاني |
| ٤٠–٤٨٫٤ | الحلقة المتميزة |
| ٤٨٫٤–٥٦ | القائمة الختامية والآية |
| ٥٦–٦١٫٨ | الخاتمة |

الصوت لم يُضف بعد.
